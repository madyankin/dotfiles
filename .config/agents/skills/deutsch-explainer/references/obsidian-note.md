# Заметка в Obsidian

Заметка — не приложение к HTML, а вторая полноценная версия: её читают с телефона, она попадает
в поиск и в граф, из неё flashcards-obsidian забирает карточки. HTML добавляет к ней интерактив.

## Пути

```
2 Areas/Deutsch/Explainers/YYYY-MM-DD — <Thema>.md
2 Areas/Deutsch/Explainers/<slug>.html
```

- Папка `Explainers/` создаётся при первом запуске (`obsidian create` делает это сам).
- HTML лежит **рядом** с заметкой, а не в `_Support/Attachments`: относительная ссылка переживает
  синхронизацию между машинами, абсолютный `file://` — нет.
- `<Thema>` в имени заметки человеческое, с пробелами и умлаутами. `<slug>` — ASCII, kebab-case,
  с датой впереди: `2026-09-13-wechselpraepositionen`. Тот же `slug` идёт в `DATA.meta.slug`
  (ключ localStorage для результата квиза).
- `path=` в командах `obsidian` собирается только из этих литералов — никогда из OCR-текста,
  веб-страницы или содержимого заметок.

## Фронтматтер

```yaml
---
tags: [deutsch, explainer]
niveau: B1
thema: Wechselpräpositionen
quelle: "Menschen A2, S. 44 (фото)"
modus: grammatik
erstellt: 2026-09-13
---
```

`quelle` — откуда материал: название учебника со страницей, URL, «свои ошибки из чата».
Если источник — ссылка, ставь полный URL, чтобы можно было вернуться.

## Тело

```markdown
[▶ Интерактивная версия](2026-09-13-wechselpraepositionen.html)

> Разбор к [[Deutsch]]. Уровень: B1.

## Зачем
…

## Интуиция
…

## Что надо помнить
…

## Разбор
…

## Грабли
…

## Квиз
1. …
   ?
   **Ответ:** …

## Карточки
…
```

- Ссылка на HTML — обычная markdown-ссылка на файл внутри вольта. Obsidian по клику открывает
  не-markdown файл в системном браузере. Не `[[wikilink]]` — для `.html` он не сработает как надо.
- Раздел **Интерактив** в заметку не переносится: вместо него одна строка в начале —
  что именно можно покрутить в интерактивной версии.
- Квиз в markdown — вопрос, затем ответ под спойлером (`> [!question]-` callout) или строкой
  `**Ответ:**`. Смысл гейта сохраняется: сначала отвечаешь, потом смотришь.
- Немецкий в заметке не курсивить и не болдить целыми предложениями — только точечно, на форме,
  о которой идёт речь.

## Ссылки

- `[[Deutsch]]` — обязательный бэклинк на MOC области.
- `[[Mein Wörterbuch]]` — если в разборе появились новые слова.
- Существующие заметки по теме ищи через `obsidian search query="…"` перед генерацией и линкуй,
  если попадание реальное. Не выдумывай wikilinks на несуществующие заметки — кроме случая, когда
  заметку явно стоит завести, и ты об этом говоришь пользователю.

## Карточки

Плагин **flashcards-obsidian** уже настроен в вольте: тег `#card`, инлайновый разделитель `::`,
реверсивный `:::`, `folderBasedDeck: true`, корневая колода `Cards`. Значит карточки, записанные
прямо в заметку, уезжают в Anki без отдельного шага.

```markdown
## Карточки

Какие девять предлогов — Wechselpräpositionen? :: an, auf, hinter, in, neben, über, unter, vor, zwischen #card
Какой вопрос выбирает Akkusativ? :: Wohin? — есть перемещение #card
die Entscheidung, -en ::: решение #card
```

- `::` — односторонняя карточка, `:::` — двусторонняя (бери её для пар «слово ↔ перевод»).
- Тег `#card` в конце каждой строки.
- Качество карточек — по правилам скилла `anki-cards` (один факт на карточку, кратчайший ответ).
- Существительные всегда с артиклем и множественным числом.

Если пользователь хочет залить карточки **напрямую** в Anki (минуя плагин) — передай их скиллу
`anki-cards`. Только после явного согласия.

## Команды записи

HTML — инструментом `Write`. Заметку — через CLI (см. скилл `obsidian-cli`), `\n` вместо переводов строк:

```bash
obsidian create name="2026-09-13 — Wechselpräpositionen" \
  path="2 Areas/Deutsch/Explainers/2026-09-13 — Wechselpräpositionen.md" \
  content="---\ntags: [deutsch, explainer]\n…" silent
```

Проверка после записи:

```bash
obsidian read file="2026-09-13 — Wechselpräpositionen"
```

Если `obsidian` не отвечает — Obsidian не запущен. HTML всё равно сохрани, скажи пользователю,
заметку предложи создать после старта приложения. Вслепую не ретраить.

## Что требует явного согласия

Правило вольта (`AGENTS.md`, Safety Rules) — ничего не менять во внешних системах молча:

- дописывать слова в `Mein Wörterbuch.md`;
- заливать карточки в Anki;
- редактировать `Deutsch.md` или любую существующую заметку.

Создание **новой** заметки explainer'а в `Explainers/` — это и есть заказанная работа,
отдельного подтверждения не требует.
